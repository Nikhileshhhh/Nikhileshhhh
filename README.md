## 🚀 Flagship Projects

### 🥇 ConfidenceOS — *AI-Powered Industrial HMI Trust Layer*

> **🏆 1st Place · ABB Accelerator National Hackathon** — beat **1,400+ teams / 14,000+ participants** across India.

`React (Vite)` `FastAPI` `Python` `WebSockets` `SQLite` `Claude API`

Industrial control rooms drown in alarms but have no answer to a simpler question: **can this reading even be trusted?** ConfidenceOS answers it in real time.

| What it does | How |
|---|---|
| 🎯 **Confidence scoring engine** | Computes live **0–100% trust scores** for sensor readings from calibration age, sensor stability, cross-sensor consistency and physical plausibility — instead of relying on alarm thresholds alone |
| ⚖️ **Mass Balance Cross-Check** | Applies **conservation-of-mass** principles to surface hidden sensor inconsistencies and physically implausible readings *before* they escalate into hazardous failures |
| 📊 **Operator dashboard** | Live confidence indicators, sensor health timelines and a **startup safety mode** in an interactive React UI |
| 🤖 **LLM shift handover** | Auto-generates shift handover reports so the next operator inherits context, not guesswork |

<br/>

### 📈 RankShala — *Founder & Full-Stack Developer*

> **200+ organic users in 2 weeks · 100 users in the first 48 hours · ₹0 marketing spend**

`React` `Vite` `Supabase (Auth + Postgres)` `Razorpay` `Edge Functions`

A college admission prediction platform that turns a student's **rank, branch, category, gender and counselling round** into a ranked list of best-fit colleges — using official historical cutoff data across **JEE Main, JEE Advanced, TG EAPCET and AP EAMCET**.
